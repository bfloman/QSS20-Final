A switch, not a dial.

Political science usually treats legislative power as a yes-or-no question: which party holds the majority. This project asks whether the size of that majority matters too. Does a party with 70 percent of the seats govern differently from one with 51 percent? The test case is Medicaid. After the 2014 expansion, a state could tighten the program with work requirements, premiums, and enrollment caps, or leave it alone. Using a complete monthly panel of 49 states from 2015 to 2026, the project sorts between two pictures: a dial, where bigger majorities restrict more, or a switch, where only holding control matters.

The answer: which party controls the legislature decides whether a state restricts Medicaid. How large the majority is does not.

+ The question

Veto-player theory says a bigger majority should be able to act more, and to do so continuously: more seats, more policy. That is a dial.

The alternative is a switch. For some policies, what matters is simply holding the majority, and extra seats add nothing once you have it. Filing for a restrictive Medicaid waiver is plausibly that kind of action: it takes control of the chamber to do, but a bare majority and a supermajority can file the same request. The paper sets these two predictions against each other.

+ The data and method

Four public sources, merged to the state-month: Medicaid and CHIP enrollment (Kaiser Family Foundation), the poverty denominator (Census ACS), legislative composition (NCSL), and restrictive Section 1115 waivers (CMS). The result is a panel of 6,515 state-months across 49 states.

The panel has real variation to work with. Across the five composition snapshots, eight lower chambers change party control, and many more shift their seat margin without crossing the line. A null on majority size is therefore a finding, not a symptom of a frozen variable.

That variation matters for the method. A two-way fixed-effects panel (state and year effects, errors clustered by state) gives the headline estimate, but a coefficient on a slow-moving variable can still reflect differences between states rather than change within them. To separate the two, restriction is also treated as a prediction problem and tested with leave-one-state-out cross-validation, and an L1 (Lasso) model is asked to choose between party control and majority size.

+ The rest of the evidence

With the complete panel, the headline regression coefficient on seat margin is positive but not statistically significant. There is no strong size effect even at face value, and three checks confirm there is none to find.

Check 1 — split by who controlsEstimating the enrollment slope separately within Republican- and Democratic-controlled chambers gives a positive number on one side and a negative number on the other, neither significant. There is no consistent size gradient on either side.

Check 2 — find where restriction happensLine states up by how Republican their legislature is and waiver use appears to rise with the margin. But it comes from three states, and one of them (Indiana, which ran a single waiver program across the whole period) carries it. Remove Indiana and the gradient reverses.

Check 3 — does it generalizeA model that predicts restriction from majority size fits its training states but predicts no held-out state (the 0.48 → 0.00 above), and an L1 model handed both party control and seat margin keeps control and drops majority size to zero.

That last point is also why the conclusion rests on restriction rather than enrollment: the enrollment measure is noisy, and a placebo association warns against trusting it. Every test that bears on size points the same way — party direction matters, majority size does not.

+ What this does not claim

This is observational, not an experiment. Eight control flips over five biennial snapshots is real variation, but it is still coarse, so the analysis can establish that no size effect is detectable without finely tracing what happens just past the control threshold. And because the enrollment outcome is noisy, the conclusion leans on the cleaner restriction evidence. The claim is not that majority size could never matter for any policy — only that, for Medicaid restriction, the data show it does not.
