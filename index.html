Direction without degree

Does the size of a legislative majority shape how a state runs Medicaid — or only which party holds it?

It's a switch, not a dial.
Ben Floman 49 states · monthly · 2015–2026 4,118 state-months
01 — The question

A majority can be a knob or a switch.

Political science usually treats legislative control as binary: which party holds the chamber. But a 51% majority and a 70% majority both "control" — and veto-player theory predicts the bigger one should govern more, continuously. That's the dial.

The alternative is a switch: for some policies, what matters is simply holding the majority, and extra seats buy nothing. Medicaid is a clean place to test which one is true — states implement it by easing enrollment or restricting it through work requirements, premiums, and enrollment caps.

02 — The data

A decade of states, assembled month by month.

Four public sources, merged to the state-month: Medicaid & CHIP enrollment (KFF), the poverty denominator (Census ACS), legislative composition (NCSL), and restrictive Section 1115 waivers (CMS).

That single control flip is the catch: with the key variable barely moving within states, a naïve model can manufacture an effect that isn't there. The analysis is built to catch exactly that.

03 — The method

Don't trust the coefficient — test whether it generalizes.

A two-way fixed-effects panel (state + year, errors clustered by state) gives the headline estimate. But because seat margin hardly varies within a state, a significant "size" coefficient can be a between-state contrast in disguise.

So restriction is also treated as a prediction problem: can a model trained on some states predict restriction in states it has never seen? Leave-one-state-out cross-validation — the honest test for panel data — answers that. An L1 (Lasso) model is then asked to choose between party control and majority size.

04 — The result

The dial appears — then dissolves under scrutiny.

One number looks like a dial: a positive, significant seat-margin coefficient. Every test designed to confirm it instead takes it apart.

Offered a choice between direction and size, the model keeps party control and throws majority size away.

05 — The takeaway

For Medicaid restriction, holding the majority is what matters — not its size.

Which party controls the chamber governs whether a state restricts; Democratic-controlled expansion states never do. But the data detect no effect of how large the majority is. Partisan power, here, behaves like a switch.

A method lesson rides along: in panels where an institutional variable barely moves within units, a standard fixed-effects model will hand you a continuous "size" effect that's really a between-state contrast — and only out-of-sample validation reveals the difference.

Honest limit: with one control flip and five composition snapshots, the panel is underpowered to resolve the shape just past the threshold. The claim is that no dial is detectable here — a failure to reject equality, not proof the effect is exactly zero. A setting with more institutional volatility could still surface a faint dial.
